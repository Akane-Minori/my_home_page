# 概要
　安部葉月のポートフォリオ用サイトをつくります  
　映像作品っぽいレイアウトにしたい
　シングルページにします


# シーン

基本の色組み合わせは青+白+茶  
夏のカフェ、的なポップでかわいい感じ  
<br>

実装する予定の場面
- タイトル
- 作者プロフィール
- 作品
  - ゲーム一覧
  - イラスト一覧
  - 音楽一覧
- 経歴

<br>
シーンチェンジの際のものの移動は
- 単色明滅
- 画面外からの登場
- 円の拡大による画面の塗りつぶし
- 拡大による登場
- 斜めブラインド登場
などを主軸に

## タイトル

映像作品のタイトル表示的なもの  
あとはボタンで各シーンに飛べるように  

## 作者プロフィール

机の上に履歴書を置いた感じ  
色はピンクと白  

## 作品一覧

３つの選択肢から選ぶ  
色はピンク+白+茶  
配置するもの
- コマ割り風の各ボタン
- フォトリアルな二値化花
- 戻る標識

## ゲーム一覧

キャラクターを並べて、クリックで説明文表示  
ダウンロードやunityroomに飛べる  
色は青+白  
登場アニメ：
- 円が拡大して画面を埋め尽くしてから薄くなって各オブジェクト配置
退場アニメ：
- 薄くなる

## イラスト一覧

マンガのコマ割り風にイラストを配置、クリックで詳細表示  
茶色ベースの暗めの画面  
配置するもの
- 各コマ
  一番左上のコマは戻るボタン
  - 途中に四角吹き出しがあり、ホバーした作品の名前とかがそこに表示される
  - ホバーすると「クリックして開く」文字
- シネスコより上のレイヤーで回転文字
- ここは縦スクロール

## 音楽一覧

音楽プレイヤー的なグラフィックとダウンロードボタンとか
色は緑+白+茶  
配置するもの
- リボン垂れ画像
- ミュージックプレイヤー
- シネスコより上のレイヤーで回転文字
登場アニメ：
- 画面外からスライド
退場アニメ：
- 薄くなる

## 日記

色はピンクと白  
jsonで記事を動的生成  

登場アニメ：
- 浮かび上がる
退場アニメ：
- 薄くなる
